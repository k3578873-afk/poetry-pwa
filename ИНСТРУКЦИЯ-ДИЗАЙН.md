# Обновление дизайна «Моя Поэзия»

1. Распакуйте архив.
2. Замените в репозитории GitHub Pages файлы `index.html` и `sw.js` файлами из этой папки.
3. Выполните Commit changes и дождитесь публикации GitHub Pages.
4. Полностью закройте приложение и откройте снова. Если старый интерфейс остался, очистите кэш сайта/перезапустите PWA.

Главная страница теперь содержит счётчик стихов, переключатель темы, поиск, избранное и список стихотворений. Категории, сортировка, сброс фильтров, перенос старых стихов, экспорт и восстановление JSON находятся в кнопке меню. Firebase Authentication, Firestore и правила доступа не менялись.
