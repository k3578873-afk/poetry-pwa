# Marufs Poetry — Firebase

## Важно: это промежуточная сборка
Вход через Google и облачное чтение подключены. Чтобы разрешить запись, нужно получить UID и настроить правила. Не публикуйте стихи до настройки правил.

1. Загрузите содержимое папки `pwa-poetry-app` в GitHub Pages (включая обновлённый `index.html` и `sw.js`).
2. Откройте сайт и нажмите «Войти через Google». Войдите своим Google-аккаунтом.
3. Откройте Firebase Console → Authentication → Users и скопируйте UID нового пользователя. Никому не передавайте пароль.
4. В `index.html` замените `REPLACE_WITH_YOUR_FIREBASE_UID` на UID (только в строке `const ADMIN_UID`).
5. В Firebase Console → Firestore Database → Rules вставьте содержимое `firestore.rules`, заменив `REPLACE_WITH_YOUR_FIREBASE_UID` на тот же UID. Нажмите Publish.
6. Опубликуйте изменённый `index.html` на GitHub. Обновите страницу (при необходимости очистите кэш PWA).
7. Проверьте: под администратором появляются кнопки «+ Стих» и «Изменить», а у обычного читателя их нет.
8. Если старые стихи сохранены на текущем устройстве, нажмите «Перенести локальные стихи в облако». Перед импортом сохраните резервную копию. Повторный импорт с теми же ID обновляет те же документы.

### Важно
- Не устанавливайте Firestore rules `allow write: if true`.
- `firebaseConfig` является публичной конфигурацией веб-клиента, но пароль и service account ключи публиковать нельзя.
- При входе через Google на GitHub Pages возможны ограничения redirect на мобильных браузерах. В коде основной способ — popup. Если вход не проходит, сообщите текст ошибки.
- Офлайн-доступ к данным Firestore в этой сборке ограничен кэшем браузера; полноценная надёжная офлайн-запись не реализована.
- Проверьте Firebase Authentication → Settings → Authorized domains: `k3578873-afk.github.io`.
