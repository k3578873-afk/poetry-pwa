# Моя Поэзия — обновление PWA

## Что добавлено
- Избранное с синхронизацией между устройствами для вошедшего пользователя.
- Категория у стихотворения и фильтр по категории.
- Поиск по названию, тексту и категории; сортировка по дате или названию.
- Экспорт библиотеки в JSON и восстановление из такого JSON (только администратор).
- Режим чтения, изменение размера шрифта.
- Сохранены Google Authentication, Firebase-конфигурация и проверка ADMIN_UID.

## Важно перед публикацией
1. Сделайте резервную копию текущих `index.html`, `sw.js` и Firestore Rules.
2. В Firebase Console → Firestore Database → Rules опубликуйте содержимое `firestore-enhanced.rules`.
   Это необходимо для синхронизации избранного. Правило разрешает каждому вошедшему пользователю доступ только к `users/{его UID}/favorites/*`.
3. Замените содержимое существующего `index.html` текстом из `index-enhanced.html`, затем сохраните изменения (Commit changes).
4. Замените содержимое `sw.js` текстом из `sw-enhanced.js`, затем Commit changes.
5. Проверьте, что GitHub Pages включён для нужной ветки/папки и дождитесь публикации.
6. Откройте сайт в браузере, обновите страницу. Если PWA установлено на главный экран и показывает старую версию, закройте его полностью, откройте сайт в браузере и подождите активации нового Service Worker.

## Безопасность и поведение
- Публичные стихи читаются всеми; создавать, изменять и удалять их может только UID, указанный в правилах и `index.html`.
- Избранное требует входа через Google и синхронизируется в Firestore отдельно для каждого UID.
- Экспорт/восстановление библиотеки доступны только UI-администратору, а фактическую запись всё равно контролируют Firestore Rules.
- JSON-восстановление перезаписывает документы с совпадающими ID; документы, отсутствующие в резервной копии, не удаляются.
- Рекомендуется сначала протестировать восстановление на небольшой копии/тестовом проекте.
